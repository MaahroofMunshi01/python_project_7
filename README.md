# Multi-Utility Toolkit

## 📌 Project Overview

The Multi-Utility Toolkit is a menu-driven Python application that combines multiple useful utilities into a single program.

It provides different functionalities such as date and time display, calendar generation, age calculation, mathematical calculations, random number generation, password generation, OTP generation, UUID generation, file handling, and Python module exploration.

This project demonstrates the practical use of Python's built-in modules and functions.

## 🚀 Features

### 1. Date and Time Utilities
- Display the current date and time.
- Generate a calendar for a specific month and year.
- Calculate age using the birth year.

### 2. Mathematical Utilities
- Calculate factorial of a number.
- Calculate compound interest.
- Calculate the area of a circle.
- Calculate the square root of a number.

### 3. Random Utilities
- Generate a random number within a specified range.
- Select a random item from a list.
- Generate secure random passwords.
- Generate a six-digit OTP.

### 4. UUID Generator
- Generate a unique UUID.
- Generate multiple UUIDs based on user input.

### 5. File Handling Utilities
- Create a new text file.
- Write content into a file.
- Read existing file content.
- Append new content to an existing file.

### 6. Python Module Explorer
- Explore built-in Python modules.
- Display available functions and attributes using the `dir()` function.

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in Jupyter Notebook or JupyterLab.
3. Open `Pr_7.ipynb`.
4. Run all the notebook cells in sequence.
5. Use the displayed menu to select the required utility.
6. Enter the requested information to get the desired output.
